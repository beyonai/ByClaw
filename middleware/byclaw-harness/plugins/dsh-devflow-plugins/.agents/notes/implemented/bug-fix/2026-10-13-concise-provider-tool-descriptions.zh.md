# Agent Note: Concise provider-facing tool descriptions

Status: implemented

[English](2026-10-13-concise-provider-tool-descriptions.md) | 中文

## 问题

百炼可能在工具执行前以 `400 data_inspection_failed` 拒绝聊天请求。同一条包含七条消息、66 个工具的请求，在五次原描述回放中有三次出现该错误。仅凭错误无法确定是 schema 缺陷、某个词语，还是平台长度限制。

## 决策

`devflow_record_iron_rule`、`devflow_read_spec`、`prepare_group_task_publication` 使用简洁中文描述，包括入参字段说明。三个顶层描述分别为 100、71、161 个字符。工具名称、输入输出 schema、执行、作用域、权限和注入顺序保持原有定义。

规则记录说明保留已确认规则的触发条件、代码和重复规则核对、持久化、script 与 judgement 的要求、只读校验及管理员规则保护。文档读取说明要求过期文档先核对代码。发布说明保留用户意图、整体替换、明确确认、文件限制，以及不得声称已经发布。

[铁律移植说明](../feature/2026-09-03-devflow-iron-rules-port.md) 仍负责持久化与执行决策；本文负责记录工具描述的语言及提供给平台的措辞。

## 考虑过的替代方案

**移除工具。** 可以避免发送这些定义，但会失去已有能力，也不能单独确认平台拒绝的原因。

**修改参数 schema 或工具顺序。** 回放保持所有非 description 字段及顺序相同。没有证据表明这些字段需要修复，修改会增加实验变量。

**认定固定字符限制或保证平台接受。** 原请求偶尔成功。观察支持这组具体措辞，无法证明存在文档规定的限制或通用修复。

## 影响

简洁描述的五次交错回放均被接受并开始 HTTP 200 SSE 流；原描述五次中成功两次。试验在初始流数据后停止，不能证明完整回答或模型选用工具成功。语言、措辞和长度同时改变，实验未单独确定是哪一项产生改善。完整请求及凭证不进入版本控制。

Loader 组合测试固定关键说明和 schema 约束。已有执行测试覆盖规则持久化及拒绝、文档读取及过期锚点、发布校验、作用域注册、持久化激活、恢复和清理。发布会话测试使用当前只读持久化句柄接口，且生命周期检查从空存储开始，确保等待写入断言实际触发写入。本地检查验证实现；部署后的模型行为仍需观察。
