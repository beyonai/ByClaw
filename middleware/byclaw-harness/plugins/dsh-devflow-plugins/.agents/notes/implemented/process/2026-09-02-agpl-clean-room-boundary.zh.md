# Agent Note: 针对 Trellis 许可链的清洁室边界

Status: implemented

## Problem

spec 缝的撰写 skill 原计划改造自一份既有的 Trellis skill。它在本工作区里是 `@byclaw/dsh-trellis`，声明 `"license": "MIT"`，其 `UPSTREAM.md` 记录了从中间 fork `1264459640/dsh-trellis` 的导入，后者同样自称 MIT。

而真正的源头是 `mindfold-ai/Trellis`，采用 **AGPL-3.0**。AGPL 是强 copyleft：下游**无权**把它重新许可成 MIT。**这条声明链上有一个断点**，而本工作区携带的那份 MIT 声明正建立在这个断点之上。

这一点对插件线尤其要紧。AGPL-3.0 把开源义务延伸到**通过网络提供**的软件，因此一个经由浏览器通道触达的衍生作品，无论是否有人分发 tarball，都背上这项义务。对一个本地脚本只是脚注的许可问题，在这里是结构性约束。

## Decision

**`packages/` 中没有任何东西派生自 Trellis。** devflow spec 缝——anchor 模型、三值裁决、结构契约、store、工具——都是在这里设计的，不欠 Trellis 任何东西。`packages/devflow-spec-tool/skills/dsh-write-spec/SKILL.md` 这份撰写 skill 是依据那套设计**清洁室写成**，而非改造而来；它正是本 Note 要约束的那件产物：本决策之前的计划写的是「改造」，而改造恰恰是许可所禁止的。

本决策划出三条线，适用于将来任何借用的冲动：

- **拿它当工具用不产生义务。** AGPL 约束的是程序本身的分发与网络提供，不触及程序所操作的文件。用 Trellis 跟踪任务没有问题，`.trellis/` 下的任务产物是我们的内容。
- **读它以评述它不产生义务。** 本次变更的规划文档描述并反驳了 Trellis 的做法——那是对一种设计的评论，不是对某种表达的复制。
- **复制或改造它的任何文本与代码都越界**，包括提示词文本、skill 正文，以及原样搬过来的目录格式约定。

AGPL 作品下游的一份 MIT 声明不是许可授予，而是一项**可能根本不成立的主张**。**当一个包宣告了上游时，把它声明的许可当作证据，而不是当作结论。**

## Alternatives considered

**信赖 `@byclaw/dsh-trellis` 的 MIT 声明。** 否决。那份声明本身就是被质疑的对象。一次中间 fork 无权进行的重新许可，不会因为被写下两遍就变得有效，而风险落在本线身上，不落在写下那份声明的人身上。

**改造 skill 并署名。** 否决。署名满足的是宽松许可，不是 copyleft。AGPL 会要求衍生作品——以及按其条款与之结合的一切——以同一许可提供，这与本线的分发方式不相容。

**因为代码本来就无关，所以认为问题不存在。** 因倒果为因而否决。这些包确实无关，但那是**独立写出来**这一事实建立的，不是跳过检查的理由。把边界记录下来，才让这份独立性日后可被审计。

## Consequences

代价是从零写一份撰写 skill，而不是改一份现成的。这个代价很小，而且有一半是错觉：这份 skill 的主题是本线自己的 anchor 模型，Trellis 原件对此无话可说。真去改造，反而会带进一套并不契合的结构。

收益是一条**写明的边界**，而不是一个假设。将来有人看到某个 Trellis 的好想法时，规则就摆在眼前——描述它、重新实现它、不要搬它的文本——以及这条规则存在的理由，即那条网络条款，而不仅仅是分发。

本 Note 不是法律意见。它记录的是在不确定下做出的工程决策；那条许可链本身，在这里的任何东西被更广泛地发布之前，值得由有资格的人复核。
