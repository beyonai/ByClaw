# Agent Note: Midscene access preparation and card reports

Status: implemented

## Problem

受保护页面需要测试身份，但新浏览器没有用户登录态。报告仅留在宿主私有目录，不便随任务证据保留。

## Decision

工作流将浏览器验收路由到现有 Midscene Skill。项目配置只记录认证要求和角色标识。登录工具导入经过授权、仅所有者可读且限于目标源的项目外快照，运行时按项目、目标源和角色选择。必需快照缺失或无效时阻止运行。快照可用不代表服务器接受：受保护用例首先断言已登录角色；SSO/MFA 准备与记录测试动作分开。

卡片报告仅复制已发布资源，运行凭据和浏览器临时文件保持私有。正式运行自动归档；探索可指定卡片或事后归档。Markdown 和 HTML 通过现有产物服务写入 journal，避开状态转换串行化；关卡运行保存卡片文件而不重入该服务。

诊断按卡片读取验收绑定；未选卡片显示未检查，不推断配置缺失。模型元数据、登录有效性、部署证据和真实执行分别说明。完成检查服务不可用时提示检查插件及依赖，不将探索证据当成正式关卡的替代品。

## Alternatives considered

**第三个 Skill。** 现有浏览器和验收流程已经负责两个阶段，新入口会重复说明。

**在套件动作里放密码。** 模型提示和报告保留动作输入，私有授权快照避免这些表面持久化密码。

**将所有运行输出移入卡片。** 运行目录包含凭据和临时浏览器文件，只有发布资源应进入任务证据。

## Consequences

项目可随卡片保留可读 HTML，并在新浏览器间复用登录态。用户仍需提供授权身份并在必要时完成交互登录。报告可能包含业务页面数据，已知凭据脱敏不等于截图匿名化。快照过期、服务器撤销或角色变化时需要重新准备。
