# 会话工作目录

ByClaw 的会话默认工作目录统一为 `/by/.sessions/{业务会话ID}`，对应聊天右侧的“过程文件”。是否属于项目不再改变 `cwd`。本地运行时使用配置的 `byRoot` 替代 `/by`；子 Agent 和同一聊天中的其他员工根会话使用同一个业务会话目录。

后端仍在 `project_info.workspace` 中提供项目空间地址，供任务需要时显式访问项目源码。项目目录和已有文件不会被搬迁、删除或自动复制到过程文件目录。HAR 中的旧上下文和历史消息保留原貌，下一次执行时会补充新的上下文声明。

## 旧会话兼容

DSH 会话头不可变。兼容层在持久化 `open/stat/list` 边界，将已确认属于 ByClaw 的旧项目工作目录转换为当前会话目录，然后交由 DSH 恢复实际 Session。会话 ID、创建时间、父子关系、历史事件、继承偏移和写入锁均保持原有语义；不会重建聊天或直接改写持久化日志。

归属确认来自 ByClaw 根元数据，或旧版本的 workspace 事件；子会话沿持久化父链确认归属。元数据的创建时间或绑定身份冲突时拒绝恢复。仅兼容 `/by/projects/{项目ID}` 及当前 `byRoot/projects/{项目ID}`，不会放开任意目录或跨会话切换。

成功恢复后，ByClaw 根元数据将工作目录更新为过程文件目录。物理 DSH 历史头保留原路径，每次 Worker 重启都通过同一兼容规则恢复。已经在旧进程中运行的 Agent 不支持热改不可变会话头；部署需正常重启 Worker，下一条消息恢复旧会话时生效。

旧团队任务的内部状态仍通过原项目工作目录对应的状态位置访问，避免切换 `cwd` 后丢失团队状态。该兼容别名不改变命令和文件工具的工作目录；新会话使用各自独立的状态位置。

## 回归检查入口

- 后端 `RouteServiceTest`：有/无项目、覆盖旧 cwd、项目资源地址保留、过程文件目录创建和复用、缺少会话 ID、目标路径为文件时拒绝发送。
- 集成插件 `scripts/session-cwd-verify.mjs`：实际 Session 恢复、历史保留、读写句柄转发、子会话/多员工归属、旧 workspace 事件、重启后恢复、身份冲突和循环父链拒绝。
- 集成插件 `scripts/session-context-verify.mjs`、`scripts/worker-verify.mjs`：上下文只更新一次、旧网关 cwd 不再决定执行目录、子会话使用业务根 ID。
- 团队插件 `scripts/catalog-cli-verify.mjs`：切换执行目录后仍能读取旧团队状态、别名冲突和释放、新会话隔离。

以上是待执行的验证入口，不表示已经运行通过；部署后的真实聊天、工具调用和 Worker 重启恢复仍需单独验证。
