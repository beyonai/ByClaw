# 场景 3：对象与视图

**触发**："什么是对象""什么是视图""对象和视图有什么区别"

---

## Step 1：接单介绍

确认收到请求，一句话介绍：对象和视图是本体的核心概念——对象存数据，视图查数据。我来给你实际演示一下它们的创建和查询过程。

## Step 2：预告演示内容

征求用户确认：

```
我要给你演示一下**对象和视图**的完整流程——

我会做三件事：
1. 创建两个对象（product 和 order），相当于建两张业务表
2. 创建视图（product_order_view），关联这两个对象实现跨表查询
3. 用自然语言查询视图，一次拿到关联结果

准备好了就说一声，我马上开始～
```

## Step 3：用户确认后演示

用户确认后，按 [05-structured-ontology](../demos/05-structured-ontology.md) 执行全部步骤：
1. create_object.py 创建 product 和 order 对象
2. create_view.py 创建 product_order_view 视图
3. mount → baiying_call 查询视图

> 演示过程中展示每一步的返回结果数据。

## Step 4：详细解释

指着刚创建的对象和查询结果数据：

> **对象**：product 和 order 就是对象——相当于数据库里的表，定义了字段结构，各自独立存储。刚才你看到创建过程就像建表一样，但不需要写 DDL。

> **视图**：product_order_view 关联了产品和订单，按产品汇总金额——一次查询跨两个对象拿结果。传统方式需要写 JOIN 语句，这里视图预设了关联关系。

> **一句话**：对象存数据，视图查数据。对象是"仓库"，视图是"窗户"。
