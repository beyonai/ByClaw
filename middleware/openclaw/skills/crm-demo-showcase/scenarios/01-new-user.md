# 场景 1：新手引导

**触发**："我是新手""给我演示一下""功能有哪些"

---

## 先演示：展示功能清单

```
CRM 综合能力演示包含以下功能，你想从哪个开始？

📊 数据查询 — 自然语言查客户、商机、项目数据
📈 数据统计 — 一句话完成聚合、排序、分组
💬 歧义处理 — 智能识别模糊表述，自动追问澄清
✏️ 数据操作 — 从非结构化文本抽取信息，录入客户、创建任务
🏗️ 本体建模 — 自己创建对象和视图，定义跨表查询
📄 非结构化融合 — 文档打标签，结构化和文档融合查询
🔒 数据安全 — 操作确认 + 权限校验

也可以说"全部演示"，我按顺序逐个展示～
```
