# 微信公众号技术文章生成器 — 参考示例

## 优秀标题模板

- `[核心数据]！[项目名]：[一句话定位]`
- `[数字]+[单位]！[项目名]让[痛点]不再[形容词]`
- `[对比词]全场！[项目名]：[领域]的「[绰号]」选手`

## 文章节奏参考

一篇好的公众号技术文章节奏：

```
痛点引入（1-2句）→ 成绩单（表格）→ 关键发现（加粗）
→ 它干啥（3-5句）→ 怎么做到（表格+短文）
→ 实战演练（命令+结果+片段，5-7个案例）
→ 性能汇总（表格）→ 谁该用（表格）
→ 总结（2-3句，有梗）→ 项目信息
```

## 禁忌

1. ❌ 不写「需要注意的坑」「局限性」「风险」
2. ❌ 不做 3 层铺垫（项目简介→目标用户→应用场景）
3. ❌ 不编造性能数据
4. ❌ 不放超过 10 行的代码块在非实战章节
5. ❌ 不用论文式段落（超过 4 行的连续文字）
6. ❌ 不在开头放「本文目录」
