# ByClaw Skill 创建与生命周期管理

## 目标与范围

在用户个人沙箱中创建、测试 Skill，并通过平台完成发布、授权、安装和卸载。适用于 OpenClaw、DeepSeek harness 等运行时，通过当前会话提供的工具与资源接口执行。

六个流程可按用户目标独立进入或衔接，不要求每次全部执行。开发文件、平台注册、用户授权、员工安装和运行时加载分别验证；只要求创建或测试时不自动发布。

## 生命周期

会话内开发、编辑和测试 → 用户验证通过 → 打包发布注册 → 平台授权与员工绑定 → 自动广播绑定元数据 → 各用户运行时自动获取文件、加载并生效。注销时先解绑，再由解绑元数据广播触发各运行时卸载。

完整对象、作用域、状态转换与完成证据见 [生命周期契约](references/lifecycle.md)。首次执行相关流程前读取；后续复用已取得的上下文。

## 输入与运行约定

- 按当前流程获取必要输入，复用会话上下文与平台查询结果。
- 在用户个人沙箱中执行，开发产物写入用户指定或当前运行时提供的可写工作目录下的独立技能目录；路径与环境解析见 [个人沙箱环境](references/container-environment.md)。
- 能力来源包括当前会话和平台注册的 API、MCP 等资源；发现、认证与调用指引见 [凭据与连接发现](references/credentials-and-connections.md)。
- 生成技能按当前执行 Agent 动态解析模型、身份与连接；所需适配能力及缺失处理见上述凭据指引。

## 核心工作流程

### 1. 创建 Skill 流程

新建前先盘点现有技能与相关业务资源，优先复用；确定新建或优化方向后，直接编写技能文件并交给测试流程。

进入该流程前读取 [创建流程](references/creation.md)：资源盘点与查重、需求引导、资源匹配、目录选择和产物规范。

### 2. 测试流程

验证技能结构与代表性任务行为，修正失败并重测，交付实际结果与未测项。

进入该流程前读取 [测试流程](references/testing.md)：验证层次、场景选择、联调范围和验收标准。

### 3. 发布流程

用户验收通过后，按已授权的目标与覆盖范围发布技能，回读资源与绑定状态。

进入该流程前读取 [发布流程](references/publishing.md)：打包、路径选择、覆盖预检、接口副作用和恢复。

### 4. 授权流程

按目标用户授予或撤销技能使用权限，只提交必要差异并回读确认；授权不等于安装。

进入该流程前读取 [授权流程](references/authorization.md)：权限核实、差异提交、分页回读和撤销边界。

### 5. 安装流程

将已发布技能绑定到目标数字员工，分别验证平台绑定与运行时生效。

进入该流程前读取 [安装流程](references/installation.md)：权限与现有绑定、增量安装、广播加载和完成证据。

### 6. 卸载流程

解除目标数字员工的技能绑定，核实保留关系与运行时卸载；卸载不等于删除平台资源。

进入该流程前读取 [卸载流程](references/uninstallation.md)：影响范围、解绑、广播卸载及注销边界。

## 共用参考与关键约束

按当前流程的执行依赖加载参考，不要求一次读取全部文档。能力发现、认证或 API 调用所需的指引应在执行前读取；已取得且仍有效的上下文可复用：

- [凭据与连接发现](references/credentials-and-connections.md)：运行时身份/模型、平台外部资源元数据、连接器/env 三类来源，以及生成技能的动态解析契约。
- [个人沙箱环境](references/container-environment.md)：会话目录、工具能力、依赖、持久化、认证连接和脱敏探测。
- [API 与脚本契约](references/api-contracts.md)：ID 语义、认证、参数、响应和随附脚本调用。
- [错误与恢复](references/error-codes.md)：部分成功、结果不明、失败定位与恢复步骤。

上传可能直接覆盖并注册资源。覆盖、删除、卸载前核实具体影响；已有明确授权覆盖同一对象和范围时继续，仅新冲突或范围变化补充确认。本技能的生命周期管理 API 操作复用 ByClawSkillAPI 及其已认证 Session，不直改数据库或存储模拟业务操作。写请求结果不明先回读，不盲目重试。

产物保持在已确定的工作区与授权路径范围内，已有内容按任务增量修改。环境诊断仅输出必要的脱敏事实，不输出凭据或完整配置。

## 验证与交付

按所执行流程的完成标准检查实际产物或逐项响应，再回读目标状态。顶层 code=0、退出码为 0 或文件存在都不能单独证明全部完成；运行时加载与实际触发单独验证。

交付实际产物路径或对象 ID、完成的流程和目标状态、验证证据，以及失败、待授权、待同步或未测项。涉及员工操作时注明目标数字员工。
