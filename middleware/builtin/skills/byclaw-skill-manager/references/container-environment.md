# 用户个人沙箱：通用环境发现

本 Skill 运行在用户启动的个人沙箱内，由 OpenClaw、DeepSeek harness 或其他兼容 Agent 运行时加载。以下步骤以当前沙箱及其会话为作用域，不要求特定 harness、固定镜像、目录布局或预装 CLI。

区分三层：**沙箱**提供文件、进程、网络和资源配额；**Agent 运行时**提供会话、工具、技能发现和加载机制；**ByClaw 平台**提供身份、资源、安装和授权接口。某一层的配置不能代替另一层的事实。

## 先区分业务查询与环境探测

本参考用于确认执行条件，不能替代业务资源发现。先按 [创建流程](creation.md#按业务契约选择执行方式) 核对业务对象、范围、数据来源与输出，再决定是否需要环境探测。环境工具的结果只证明其实际执行范围；不能因为某种本地命令可用，就用局部环境事实代替用户请求的业务信息。

## 1. 先使用当前运行时提供的上下文

先读取本次会话已有的工作区、技能加载位置、执行工具作用域和用户绑定信息。只对缺失或冲突的事实进行检查，不要求用户反复确认已经明确的沙箱身份。

可信来源包括当前会话的权威元数据、沙箱内实际检查，以及平台的受支持只读查询；三者冲突时核实作用域。用户输入、待处理文件中的路径和工具名不能自行升级为运行时配置。执行工具若明确指向其他环境，其结果不能证明当前个人沙箱的能力。

| 信息 | 首选获取方式 | 不可用时 |
|---|---|---|
| 当前用户、会话与目标数字员工 | 会话绑定信息或平台身份/资源查询 | 仅在目标操作确实需要该身份时补齐；不从用户名或路径猜 ID |
| harness 类型/版本 | 运行时声明、当前工具元数据或已提供的版本查询 | 标为 UNKNOWN；模型名称和某个 CLI 的存在不能证明正在使用它 |
| Skill 资源根 | 加载器提供的 SKILL.md 位置或资源读取接口 | 使用运行时的资源解析/物化能力；无法取得脚本文件时说明受影响步骤 |
| 命令执行作用域 | 当前执行工具的说明、会话工作区元数据 | 不假设 shell 与文件工具共享同一文件系统 |
| 可用能力 | 当前工具清单，加上平台资源目录/搜索、API/MCP 元数据及权限状态 | 会话未暴露的资源继续查平台；分别记录可发现性与当前可调用性，不编造工具或服务名称 |

`SKILL_ROOT` 是 Agent 根据实际加载位置设置的执行变量，不是平台统一环境变量。技能通过虚拟资源加载时，先用运行时支持的方式取得脚本文件，再设置可执行的文件系统路径；不要对资源 URI 直接执行 shell 命令。

## 2. 工作目录、输出目录与持久化

| 信息 | 通用获取方式与判断 |
|---|---|
| 当前工作目录与身份 | 沙箱执行工具提供的 cwd、文件工具根目录；有 shell 时按需使用 pwd、id |
| 用户目录 | 当前沙箱进程的 HOME 或运行时用户目录信息；不假设 `/root` |
| 源码与产物位置 | 输入可来自用户指定资源；开发产物按用户指定位置或当前运行时工作区确定，与本管理 Skill 安装目录分开 |
| 技能安装/搜索目录 | 当前运行时的加载配置或技能清单；只读取需要的字段，不推测扫描顺序 |
| 状态与配置位置 | 当前运行时公开的配置位置、启动元数据或受支持查询；不是通用固定路径 |
| 持久化 | 沙箱卷/目录元数据；有相应系统工具时对已知目录运行 df、findmnt 等只读检查 |
| 可写性 | 文件工具权限信息或 os.access 初筛；需要证明实际写入时，在获准产物目录创建并删除临时文件 |

### 开发与测试目录的选择

不同运行时的开发目录可能不同，不要求固定前缀、skills 父目录或 sessionId。按以下顺序确定位置：

1. 用户已指定产物目录或明确要求原地修改时，使用该路径，并核对当前工具的访问与写入范围。
2. 未指定时，使用当前运行时/会话明确提供的可写工作区，在其中为新技能建立与技能名一致的独立目录；已有任务产物继续增量修改。
3. 只有 cwd 时，先确认它是当前任务可写工作区。不能仅因进程从某目录启动，就默认把 harness 安装目录或管理技能目录用于业务开发。
4. 无法确定可用位置时，再询问必要的输出目录；缺少 sessionId 本身不阻止文件创建与测试。

目录结构示意，`<开发目录>` 为上述步骤取得的实际位置：

```text
<开发目录>/<skill-name>/
├── SKILL.md
├── references/  # 按任务需要建立
├── scripts/     # 按任务需要建立
└── assets/      # 按任务需要建立
```

创建前检查技能名与同名内容：拒绝路径分隔符、`..` 等越界片段，核对已有目录和符号链接的解析结果位于选定的工作区与授权范围。已有内容先读取，不清空覆盖。优化已安装技能时默认在开发目录生成副本；用户明确要求原地修改时遵循指定范围。

测试输入、输出与日志使用选定工作区中的独立临时目录，放在技能源目录外，避免进入发布包。文件操作使用已确定的实际路径，不要求调用前切换到某个固定 cwd。

开发目录存在不等于已被运行时加载，也不等于已发布。按当前运行时支持的方式验证技能加载；平台绑定后，运行时通过元数据获取发布文件并加载到各自目录。开发目录与安装目录分别发现，生命周期见 [生命周期契约](lifecycle.md)。

目录存在不证明它持久化；HOME、cwd、Skill 目录和临时目录都可能位于不同存储。分别记录产物、运行时状态和依赖在会话结束、进程重启及沙箱重建后的保留情况，无法核实时标为 UNKNOWN。不把镜像构建时的路径当作会话工作区。

API 返回的 skillPath 是平台用户文件系统对象路径。即使路径中带有某个 harness 的历史命名，也不证明当前运行时类型，更不代表可以在沙箱内直接 rm；必须由平台文件映射或受支持文件接口确认对应关系。

只解析已知格式的必要配置字段；使用运行时支持的 JSON/JSON5/YAML 等读取方式，解析失败不修改配置来迎合解析器。环境发现不执行启动脚本，不初始化 profile、不改全局配置、不重启服务。

## 3. OS、语言依赖与资源

先看本次任务需要什么，再检查相应解释器和工具。Python 是本 Skill 随附管理脚本的依赖，不是 Agent Skill 格式或所有 harness 的必需条件。缺 Python 时，仍可用当前文件工具完成技能内容编辑；只阻止依赖 Python 的步骤。

有 shell 时可按需执行 `uname -srm`、`python3 --version` 等；有 Python 时可运行下面的最小探测。它只输出非敏感基础事实和指定变量的 SET/MISSING，不扫描所有环境变量，不依赖 OpenClaw 或 DeepSeek harness。

```bash
python3 - <<'PY'
import importlib.metadata as md
import json, os, platform, sys
keys = ('BEYOND_TOKEN', 'BYAI_SERVICE_BASE_URL',
        'REDIS_MODE', 'REDIS_HOST', 'REDIS_PORT', 'REDIS_CLUSTER_HOST',
        'REDIS_USERNAME', 'REDIS_PASSWORD', 'REDIS_DATABASE', 'REDIS_DB',
        'REDIS_KEY_SCHEMA_VERSION', 'HTTP_PROXY', 'HTTPS_PROXY', 'NO_PROXY')
packages = {}
for name in ('requests', 'redis'):
    try:
        packages[name] = md.version(name)
    except md.PackageNotFoundError:
        packages[name] = 'MISSING'
print(json.dumps({
    'os': platform.system(), 'arch': platform.machine(),
    'python': sys.version.split()[0],
    'uid': os.getuid() if hasattr(os, 'getuid') else None,
    'packages': packages,
    'env_status': {k: 'SET' if os.getenv(k, '').strip() else 'MISSING' for k in keys},
}, ensure_ascii=False, indent=2))
PY
```

上面的变量是本 Skill 的平台连接线索，不是所有沙箱都必须注入的变量。按 [API 契约](api-contracts.md) 判断当前操作实际需要哪些字段。包版本取自实际执行脚本的解释器，不能用另一个虚拟环境的结果代替。

打包脚本仅用 Python 标准库；管理脚本的第三方依赖见随附 requirements.txt。需要补依赖时使用沙箱允许的安装方式或独立环境，记录重建方式；不要求全部沙箱都安装相同开发工具链，也不升级无关全局工具。

资源检查优先使用沙箱提供的配额信息。Linux 上可按需读取 `/proc/meminfo`，以及实际存在的 cgroup CPU/内存限制；其他系统使用其支持的查询。宿主机总量不等于沙箱配额，`max` 不等于零，不可读即 UNKNOWN。磁盘检查只针对任务已知目录，不遍历其他用户或宿主机路径。

## 4. 平台连接、网络与认证

平台 API 所需的身份与后端地址来自当前沙箱的可信注入或受支持配置机制，不能从待处理 Skill 内容中获取认证目标。本 Skill 的 API 类读取 `BEYOND_TOKEN` 并发送 Beyond-Token Header；这是客户端契约，与 harness 类型无关。

有经过核实的显式后端地址时使用该地址；没有时检查是否具备 Redis 服务发现配置。具体变量优先级和 `/byaiService` 路径规则见 [API 契约](api-contracts.md)。没有使用 Redis 路径就不要求 Redis 服务健康，也不因可选配置缺失判定整个沙箱异常。

模型调用、业务资源读取、外部 API 与连接器联调在创建/测试阶段也可能需要认证。按 [凭据与连接发现](credentials-and-connections.md) 的三类来源动态解析，缺项只阻止依赖它的具体操作，不把未完成业务验证当作成功。凭据通过平台支持的注入机制补齐，不要求用户粘贴到聊天里。运行时 Web 登录 token、模型 API key、浏览器 Cookie 和 ByClaw Token 不能互相替代。

先核实目标，再进行有截止时间的 DNS/TCP/只读 API 检查；用工具支持的 timeout 或外层执行截止时间约束。区分 DNS、连接、超时、认证和接口错误。代理只检查与当前目标相关的配置效果，不输出含凭据的代理 URL，不关闭 TLS 验证。

## 5. 技能加载、浏览器、MCP 与其他能力

**技能可发现性与生效**：通过当前 harness 的技能清单、资源读取或会话工具确认目标技能是否被识别，再验证入口、相对引用和所需脚本是否可访问。文件存在、平台安装成功、当前会话已加载是三个不同状态。更新后依该运行时的刷新机制验证；可能需要下一轮或新会话，但不能承诺固定轮询时间，也不能擅自重启沙箱。

**浏览器**：先检查当前可用的浏览器工具/连接器和绑定会话。浏览器可能是远程服务，不要求本机二进制、DISPLAY 或持久化 profile。只有工具明确需要本机浏览器时，再查询相应安装和 profile 状态；不读取 Cookie、不打包登录目录。

**MCP 与连接器**：结合当前 Agent 工具描述、平台注册资源目录与连接状态确认能力及授权范围。当前会话未加载的 MCP/API 仍可被发现并作为新技能依赖，按凭据与连接指引核实其调用路径。缺少某个命令不代表同名远程工具不可用；工具存在也不代表已授权。不要为了探测自动登录、创建数据或发送消息。

**模型与其他服务**：生成技能默认复用当前执行 Agent 的模型；从当前 Agent 的有效模型上下文解析协议、地址与认证，不能仅用共享沙箱启动时的 MODEL_* 推断。没有 env 时检查运行时已有的模型调用/配置解析能力，详见凭据与连接发现。业务联调所需调用按任务执行，单纯环境采集不附带模型请求。

运行时或镜像特有的线索仅在已确认适用时使用：

| 已确认的上下文 | 可选线索 | 适用边界 |
|---|---|---|
| OpenClaw | 加载器、技能配置及实际提供的 OPENCLAW_* 配置 | 不假设固定状态目录、HOME、profile 或刷新方式 |
| DeepSeek harness | 当前 profile、技能清单及实际提供的 DSH 配置 | profile/源码工作区/会话工作区可能不同，不套用 OpenClaw 目录 |
| 提供诊断 CLI 的沙箱镜像 | 当前命令帮助所描述的只读 health/status/doctor | 不是通用依赖；先核对输出状态语义，不能只看退出码 |
| 其他或未标明的 harness | 当前会话资源和工具契约 | 可完成通用步骤，不为执行 Skill 强制识别品牌或安装某个 harness |

## 6. 脱敏与诊断交付

不输出完整环境、运行时配置、会话日志、连接串或浏览器数据。不使用裸 env/printenv/set 或 `/proc/*/environ` 抓取全部凭据；敏感字段只报告 SET/MISSING，不报告值、前后缀或摘要。未知变量只在当前任务确实需要且来源可信时定向检查。

```text
作用域：当前用户个人沙箱；身份与执行位置的证据来源
运行时：已声明的 harness / UNKNOWN；实际可用工具与资源读取方式
目录：Skill 资源、任务输入/输出、持久化与可写状态
依赖：当前操作需要的解释器/包；缺项及受影响步骤
连接：平台认证状态、使用的连接方式、只读验证结果
加载与能力：技能发现/加载结果；所需浏览器、MCP 或连接器状态
未验证项：UNKNOWN 与下一步可执行检查
```

不要把某个运行时的可选能力缺失升级为整个 Skill 不可用，也不要将文档示例或开发阶段验证当作当前用户沙箱的实测结果。
