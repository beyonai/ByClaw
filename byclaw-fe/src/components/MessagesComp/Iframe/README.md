# iframe 预览高度

`IframeRender` 默认填充父容器，外部页面仍可发送 `iframe-set-height` 消息设置高度。

会话消息中的 HTML 代码块通过 `HtmlRunner` 开启 `autoHeight`，将同源 Blob 文档的内容高度同步到 iframe。加载完成、内容变化、图片或字体加载以及预览宽度变化都会触发重新测量；代码/运行视图切换后也会按可见宽度重新计算。

聊天流式输出期间沿用代码视图，消息完成后才挂载 HTML 预览并测量最终高度。预览文档加载后动态追加内容也会重新测量；本组件不改变代码流式输出期间的预览时机。

测量会临时清除旧视口高度的影响，以支持 `min-height: 100vh` 页面在内容缩小时收缩。尺寸变化通过动画帧合并处理，iframe 自身仅高度变化不会再次触发宽度测量。切换 URL、重新加载或卸载时清理观察器和待执行测量。

跨域文档无法读取时保留原有高度，不进行内容测量。

收到 `iframe-set-height` 时，显式高度优先：停止当前文档的自动测量并取消待执行测量，继续接受数字像素值或 CSS 高度字符串。同一文档首次加载完成也保留显式值，加载新文档后恢复自动测量。
