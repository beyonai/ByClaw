# MainDrawer 层级约定

普通模式（`overlay: false`）在主页面布局内显示远程桌面或文件预览。内部 `.myDrawer` 不设置高于全局弹层的层级，调用链详情等 Ant Design Drawer 应完整覆盖它。关闭全局 Drawer 后，原有远程内容和交互状态继续保留。

覆盖模式（`overlay: true`）用于运营账号登录。外层 Ant Design Drawer 负责遮罩和层级，使用 `zIndex={1300}`，高于项目账号面板 `.detailPanelOverlay` 的 `1000`。账号登录所需的覆盖关系由外层 Drawer 保证，不依赖普通模式的内部样式。

`__tests__/layering.test.tsx` 实际编译 MainDrawer 和 PCLayout 的 Less，渲染真实 MainDrawer、事件订阅和 Ant Design Drawer，验证普通模式层级、关闭后的内容保留，以及账号登录覆盖模式。仅替换远程桌面、预览和移动页面等内容边界。

JSDOM 测试检查计算样式和组件状态；遮罩的视觉覆盖与鼠标命中需要另行使用浏览器验证。远程沙箱连接、平台扫码与登录状态保存属于后端集成验证范围。

## 聊天远程桌面入口

会话模式的标题栏始终提供远程桌面入口，包括已进入会话但尚无正式会话 ID 的阶段。首页欢迎模式不显示会话标题栏；上传文件提前生成 ID 后，仍保持欢迎模式直到发送消息。历史消息只恢复 `instanceRefs` 关联，不自动展开；“全部桌面”从当前身份的授权目录选择精确的 sandboxId、mappingId 和 instance。

工具消息的“查看桌面”通过当前聊天的 `EventEmitter` 通知对应 `MainDrawer`，不使用窗口级广播。嵌套应用会话拥有独立事件总线，打开其桌面时保留外层承载应用的抽屉与会话内容。

上传接口、WebSocket 和历史消息的会话 ID 可能为数字或字符串，归属比较使用归一化 ID。无 ID 的手动选择暂存于局部 temporary owner，正式 ID 出现后迁移关联与偏好；自动展开必须有正式 ID。存为模板等依赖已保存会话的操作仍只在有 ID 时显示。

首次实时工具引用可自动展示，已有其他工作面板时不抢占；后续引用只追加关联。原子 `beyond-drawer-view` 请求携带视图句柄，旧视图的更新/关闭不能覆盖新视图。关闭后仍可从标题重新打开，工作区只挂载当前选中的一个 iframe。

标题和实时处理器可同时持有同一个 owner；只有最后一个挂载者离开才释放其可见桌面，不清除会话关联。身份切换清除旧身份的关联、目录及当前 iframe，同时保留仍挂载的聊天上下文，让新身份首次实时消息无需切换路由也能正常处理。

`__tests__/vncReopen.test.tsx` 使用真实 opener、事件总线、入口和抽屉关闭链路，验证新回复出现后关闭、再打开桌面；仅替换远程 iframe 内容边界。

新建会话发送首条消息时，流上下文可能先于正式会话 ID 注册。浏览器事件处理器使用稳定回调读取最新 opener，避免后续工具事件仍调用 temporary owner 并因缺少 ID 跳过自动展示；当前会话归属检查继续过滤切换会话后的旧消息。`src/hooks/__tests__/useHandler.vncLifecycle.test.tsx` 保留注册时的流回调，使用真实流上下文、处理器、opener、事件总线和抽屉，覆盖首轮消息有/无 `instanceRefs` 自动打开，以及切换会话后的旧消息不打开桌面。
