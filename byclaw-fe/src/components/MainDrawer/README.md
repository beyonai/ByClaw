# MainDrawer 层级约定

普通模式（`overlay: false`）在主页面布局内显示远程桌面或文件预览。内部 `.myDrawer` 不设置高于全局弹层的层级，调用链详情等 Ant Design Drawer 应完整覆盖它。关闭全局 Drawer 后，原有远程内容和交互状态继续保留。

覆盖模式（`overlay: true`）用于运营账号登录。外层 Ant Design Drawer 负责遮罩和层级，使用 `zIndex={1300}`，高于项目账号面板 `.detailPanelOverlay` 的 `1000`。账号登录所需的覆盖关系由外层 Drawer 保证，不依赖普通模式的内部样式。

`__tests__/layering.test.tsx` 实际编译 MainDrawer 和 PCLayout 的 Less，渲染真实 MainDrawer、事件订阅和 Ant Design Drawer，验证普通模式层级、关闭后的内容保留，以及账号登录覆盖模式。仅替换远程桌面、预览和移动页面等内容边界。

JSDOM 测试检查计算样式和组件状态；遮罩的视觉覆盖与鼠标命中需要另行使用浏览器验证。远程沙箱连接、平台扫码与登录状态保存属于后端集成验证范围。

## 聊天远程桌面入口

加载历史会话时，标题栏远程电脑入口只判断当前会话最新一条数字员工消息中的浏览器活动，不回溯旧回复，也不自动打开桌面。

上传接口、WebSocket 和历史消息的会话 ID 可能为数字或字符串。上传回调和全局会话状态写入统一使用字符串；VNC 的消息归属、最新员工消息筛选与打开成功事件使用归一化后的非空 ID 比较。同一 ID 仅改变传输类型不算切换会话，不取消待打开请求或重置入口；不同 ID 和空 ID 不能误触发开窗。

当前会话成功取得有效 VNC 地址并打开面板后，`useVncOpener` 发出带会话 ID 的 `beyond-chat-vnc-opened` 事件。入口保留至切换会话或离开页面，关闭面板、发送新消息和新回复尚无浏览器活动都不会清除它。保留的入口可以再次手动打开桌面。沙箱未就绪、打开请求失败或已取消时，不保留入口。

切换会话（包括 A → B → A）时重置已打开状态，并清理旧事件监听及待打开请求。历史入口首次打开时仍核对最新回复；已经打开过的当前会话再次打开时，不要求回复 ID 保持不变。

`__tests__/vncReopen.test.tsx` 使用真实 opener、事件总线、入口和抽屉关闭链路，验证新回复出现后关闭、再打开桌面；仅替换远程 iframe 内容边界。
