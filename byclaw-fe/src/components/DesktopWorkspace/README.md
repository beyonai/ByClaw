# 远程桌面工作区

工作区使用授权 `getSandboxInfo` 清单解析 `SandboxInstanceRef`，身份为
`[sandboxId, mappingId ?? null, instance]`，不会从工具输出读取 URL 或凭证。
共享沙箱必须完整匹配 mappingId。仅 `presentation.viewer=novnc` 及旧版明确
`vnc`/`desktop` 入口进入桌面选择器，需请求头鉴权的入口须先提供服务端可导航访问适配器。

当前会话的首次有效实时引用可自动展开一次。后续引用只登记；历史恢复不会自动展开。
手动打开、收起、切换工作面板及会话会取消等待中的自动展示。收起或切换仅卸载当前观看 iframe，
不会停止沙箱或业务任务。连接状态只代表当前观看连接；旧镜像未上报事件时显示“状态未上报”，
用户可通过父工具栏重新获取授权入口并重新连接。

通过现有 Umi 环境变量入口设置 `UMI_APP_MULTI_DESKTOP_ENABLED=false`，可关闭自动展开及
多页签交互；仍保留手动入口、授权选择器与已知实例的精确单画面查看，不降级为列表首项。
引用生产开关由运行时单独控制。当前默认启用，发布时应按已验证的提供者组合配置。

实例关联、隐藏、最后选择及已处理首次机会按账号、企业和 owner 存储于当前标签页的
sessionStorage。URL、token、headers、channelId 和实时连接状态不进入偏好。认证变化立即清理
内存与当前标签页偏好并卸载视图；旧认证请求结果不得写回目录。目录订阅和同源暖机共用
60 秒准备预算，最多 30 次，单次请求最多 5 秒；跨域入口不依赖 CORS fetch 探测。

独立运营登录使用 `utils/drawerView` 的原子 `openDrawerView`，保存返回的 owner/代次句柄，
后续更新和关闭必须携带该句柄。后来的聊天或文件视图会作废旧句柄，晚到登录回调不能覆盖它们。
录制器保留独立 iframe 和录制生命周期。
