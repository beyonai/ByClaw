# 日志管理

日志表格展示时间、模块编码、级别、来源和日志内容。模块编码取自日志属性 `attributes.moduleCode`，缺少该属性时单元格留空；展开行可查看完整日志属性。

查询条件支持模块编码，留空查询全部模块。前端通过 `moduleCode` 传参，后端将其透传至平台日志查询接口；翻页沿用已提交的查询条件，重置清除模块编码。

接口另支持可选 `instanceID` 入参，对应 SLS 的 `instanceID` 字段，与原有 `sandboxId` 独立；同时传入多个条件时按 AND 组合。页面现有输入项保持不变。

时间范围位于查询卡片右上角。筛选项采用标签在左、控件在右的布局，宽屏第一行依次展示模块编码、实例标识和日志级别，第二行展示关键词及查询操作；中等屏幕分为两列，手机屏幕按单列排列，筛选项内部仍保持左右布局。
