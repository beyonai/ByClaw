# 权限标识大小写兼容

权限比较忽略账号与角色编码的大小写，不修改存储值或接口原始值。

- 前端 AdminVip 判定以及企业技能组后端名单匹配，同时兼容默认账号和 USERCODE_CONFIG 配置账号。
- 前端角色入口通过 hasAnyUserRole 比较，后端角色权限通过 UserType.matchesAny 比较。
- 平台管理员兼容 PLAT_MAN、plat_man、Plat_Man；最高角色计算仍返回规范的大写编码。
- 各业务允许的角色名单保持不变，平台运维、组织管理员、业务管理员不会因此获得仅属于平台管理员的权限。
- 本次不修改角色写入校验和持久化约束；新数据仍应使用规范角色编码。

回归用例覆盖初始化与配置加载后的账号大小写、技能组创建/删除/上下架、数字员工创建入口、官方技能导入能力及公共角色判断。测试执行由开发者按需安排。
