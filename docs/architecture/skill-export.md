# 资源中心技能导出

技能卡片提供导出，技能列表提供全导出，所有能浏览列表的登录用户均可操作，不要求编辑、管理或导入权限。
全导出遵循当前页签、搜索和筛选，遍历全部分页，包含该列表中的工作空间技能；不会只导出已滚动加载的卡片。

单项导出沿用 `/tool/downloadSkillZip`，资源化技能保留原始 ZIP，工作空间技能按目录打包。
内置技能按数据库 resourceCode 从当前用户 OpenClaw 镜像 `/app/skills/<code>` 读取完整目录，保留文件执行权限，展开依赖链接。
使用现有 UserSandboxResolver 和 SandboxCommandExecutor；运行环境不可用、文件缺失、依赖循环、打包超时或大小超过 64 MiB 时返回失败，不用资源描述生成替代文件。

全导出生成 `skills.zip`，其中 `byclaw-skills.json` 声明 `byclaw-skill-packages-v1` 格式及各包原始文件名，`packages/<index>.zip` 保存原始字节。
资源中心导入入口自动还原这些原始 ZIP，再走原有冲突预检查和批量导入接口，无须手工解压。原始文件名必须保留：SKILL.md 位于 ZIP 根目录时，导入按文件名推导技能编码。
批量导出任何一个技能失败则整体失败，不下载不完整集合。导入仍遵循原有目录、归属和覆盖权限；导出权限不授予覆盖资源的权限。
