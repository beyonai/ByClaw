# Web 消息分享入口恢复

## 范围

- ByClaw Web 前端，`develop` 分支。
- 恢复已完成、已取消回答下方的“分享”按钮，复用现有中英文文案及消息多选流程。
- 点击“分享”时先选中当前消息，再打开分享多选栏；点击“链接分享”进入有效期设置。

## 页面验证步骤

1. 打开聊天，找到一条已完成的回答。
2. 在回答下方“复制、保存”同一排找到“分享”。
3. 点击“分享”，确认当前消息已选中，底部显示“链接分享”。
4. 点击“链接分享”，选择自定义有效期并清空天数，再点击“创建链接”。
5. 确认显示必填提示，且没有发送创建链接请求。
