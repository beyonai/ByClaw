# 员工技能配置

创建员工时，在配置页面点击技能区域的添加按钮，打开“配置技能”弹窗。

- 个人数字员工：显示“个人技能”和“企业技能”两个 tab，默认打开个人技能。
- 企业数字员工：仅显示“企业技能”tab。
- 搜索和滚动加载限定在当前 tab 的归属范围内；切换 tab 时清空搜索条件并从第一页加载。
- 切换 tab 保留已经选择的技能，可跨 tab 继续添加或移除技能。

技能列表沿用现有资源接口的可见性和权限规则。

## 当前员工技能菜单

展开技能菜单时，系统检查员工目录中的 `SKILL.md` 与资源库技能包中的 `SKILL.md`，按文件原始内容的 MD5 判断是否需要更新，已安装技能也参与检查。

- 未入库的目录技能显示“安装”。
- 文件内容不一致且具有更新权限时显示“更新”，不同时显示“卸载”。
- 已安装技能的文件内容一致时显示“卸载”。
- 检查中或检查失败时显示检查状态或重试入口，不预判为内容一致。

已安装技能更新时按员工实际绑定的资源 ID 保存，保留员工目录和安装关联。未入库目录技能的安装仍沿用保存成功后清理源目录的流程。
