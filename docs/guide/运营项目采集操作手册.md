# 运营项目采集操作手册

本文档面向使用 ByClaw 运营项目完成资料采集、整理和归档的业务人员，按当前系统页面说明从创建项目到查看采集成果的完整操作流程。

> 文档更新时间：2026-08-08。不同账号能够选择的知识库、数字员工、本体和项目成员由当前账号权限及项目绑定资源决定。

## 一、整体流程

```mermaid
flowchart LR
    A[创建运营项目] --> B[绑定项目资源]
    B --> C[新建采集需求]
    C --> D[拆分运营需求]
    D --> E[生成待开始任务]
    E --> F[选择素材采集任务模板]
    F --> G[填写采集与执行配置]
    G --> H[启动任务并进入会话]
    H --> I[数字员工执行采集]
    I --> J[查看文件或本体成果]
```

核心操作顺序为：

1. 创建运营项目并绑定知识库、数字员工和本体。
2. 在需求 Tab 新建采集需求。
3. 将需求拆分为一项或多项可执行任务。
4. 在任务 Tab 启动待开始任务。
5. 选择“素材采集任务模板”，填写结构化采集配置。
6. 系统自动进入任务会话并发送任务提示词。
7. 在会话中跟踪执行进度，并通过资源面板查看成果。

## 二、使用前准备

开始采集前，请确认以下内容已准备完成：

| 准备项 | 说明 |
| --- | --- |
| 项目权限 | 当前用户能够创建项目，或已加入目标运营项目 |
| 知识库 | 当前账号至少有一个可用的个人知识库或企业知识库 |
| 数字员工 | 当前账号至少有一个可用的个人助理或数字员工 |
| 本体 | 当前账号至少有一个可用的个人本体或企业本体 |
| 连接器 | 如选择连接器采集，应确认对应平台连接器可正常访问 |
| 项目成员 | 需求负责人和拆分任务负责人应为当前项目成员 |

## 三、创建运营项目

### 3.1 进入新建页面

1. 点击系统左侧主菜单“项目”。
2. 在项目列表搜索框右侧点击“新建”按钮。
3. 在“新建项目空间”弹窗内填写项目信息。

弹窗内容区域支持独立上下滚动，不会带动整个系统页面滚动。

### 3.2 填写基本信息

| 字段 | 是否必填 | 填写说明 |
| --- | --- | --- |
| 项目名称 | 是 | 最多 100 个字符，项目名称不能与已有项目重复 |
| 项目描述 | 否 | 默认展示两行，最多 500 个字符 |
| 项目类型 | 是 | 使用 Tab 样式选择“运营项目” |
| 是否共享 | 系统控制 | 运营项目固定为共享项目 |

如果创建失败，页面会直接展示接口返回的错误信息，例如“项目名称已存在”。

### 3.3 绑定项目资源

运营项目必须绑定以下三类资源，三类资源均为必填并支持多选：

| 资源类型 | 数据范围 | 后续用途 |
| --- | --- | --- |
| 知识库 | 当前账号可用的个人知识与企业知识 | 知识库采集、目标知识库入库、项目共享知识库 |
| 数字员工 | “员工”模块中的个人助理和数字员工 | 任务模板中的执行主体 |
| 本体 | “本体”模块中的个人本体和企业本体 | 本体入库、项目共享本体 |

任务模板中的来源知识库、目标知识库、数字员工和本体，只能从当前项目已绑定的资源中选择。

### 3.4 配置项目成员

运营项目创建者会自动作为项目成员保留。创建后可进入项目详情的“成员”Tab：

1. 点击右上角“添加成员”。
2. 在组织成员面板中搜索或按组织选择人员。
3. 在右侧“已选择”区域确认最终成员。
4. 点击确定，一次性保存项目最终成员集合。

项目创建者不能被删除。成员卡片鼠标经过后，可根据权限执行绑定数字员工、更换数字员工、解绑数字员工或移除成员等操作。

> 任务模板选择数字员工时直接使用项目绑定的数字员工，不再校验任务负责人是否单独绑定数字员工。

## 四、新建采集需求

### 4.1 进入需求 Tab

打开运营项目大详情页面，顶部 Tab 顺序为：

1. 账号
2. 需求
3. 任务
4. 资源
5. 成员

切换到“需求”Tab，点击右上角“新增需求”。新增完成后页面仍停留在需求 Tab。

### 4.2 填写需求信息

| 字段 | 是否必填 | 默认值或说明 |
| --- | --- | --- |
| 需求名称 | 是 | 简要描述本次采集目标 |
| 需求描述 | 否 | 补充采集范围、质量要求、来源要求等信息 |
| 需求类型 | 是 | 素材采集与整理、内容创作与发布、数据分析与优化等 |
| 指定成员 | 是 | 默认当前登录用户，可选择其他项目成员 |
| 预期时间 | 是 | 默认当前日期一周后 |

采集的执行方式不在需求页面配置，而是在任务启动时选择任务模板后填写。

### 4.3 推荐填写示例

| 字段 | 示例 |
| --- | --- |
| 需求名称 | 采集企业 AI Agent 落地案例 |
| 需求描述 | 采集近一个月企业 AI Agent 落地案例，保留原始来源，并提炼企业、行业、应用场景和落地效果 |
| 需求类型 | 素材采集与整理 |
| 指定成员 | 当前用户 |
| 预期时间 | 一周后 |

## 五、拆分运营需求

待开始的运营需求卡片在鼠标经过时显示“拆分任务”按钮。

### 5.1 默认拆分结果

点击“拆分任务”后，系统会结合原需求名称默认生成三项任务：

1. `需求名称 - 素材采集`
2. `需求名称 - 素材整理`
3. `需求名称 - 知识归档`

每项任务都包含：

- 任务名称
- 任务描述
- 负责人

### 5.2 调整拆分任务

在“拆分运营需求”页面可以：

- 修改任务名称。
- 修改任务描述。
- 为每项任务选择负责人。
- 点击“新增任务”继续添加任务。
- 删除不需要的任务，删除前系统会进行二次确认。

点击右下角“确定”后，系统生成待开始任务，并自动切换到任务 Tab。

## 六、启动采集任务

### 6.1 打开任务模板

在“任务”Tab 找到状态为待开始的任务。鼠标经过任务卡片后，右上角显示“执行”按钮：

1. 点击“执行”。
2. 打开“选择任务模板”页面。
3. 选择“素材采集任务模板”。
4. 进入模板详情并完善结构化信息。

待开始任务未执行前不显示“打开任务会话”；任务启动后不再显示“执行”按钮。

### 6.2 填写任务基础信息

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 任务名称 | 是 | 默认带入拆分任务名称，可修改 |
| 采集内容描述 | 是 | 默认带入任务描述，可补充采集主题、范围和结果要求 |

## 七、配置采集方式

采集方式默认选中第一个可用选项。当前支持三种方式：

### 7.1 连接器采集

选择“连接器采集”后，在右侧选择连接器。当前页面可选项以系统实际配置为准，例如：

- 钉钉
- 企业微信
- 飞书

适用于从已接入的企业协作平台或内容平台采集资料。

### 7.2 互联网采集

选择“互联网采集”后，填写搜索范围，例如：

```text
公开网页、行业媒体和微信公众号文章，重点关注近一个月发布的企业 AI Agent 落地案例。
```

建议明确时间范围、站点范围、主题关键词和需要排除的内容。

### 7.3 知识库采集

“知识库采集”位于采集方式的最后一个选项。选择后需要选择“来源知识库”。

来源知识库只展示当前项目绑定的知识库数据，不会展示项目外未绑定的知识库。

## 八、配置入库方式

入库方式默认选中第一个选项“本体”。当前支持两种方式：

### 8.1 本体入库

1. 选择“本体”。
2. 在右侧“本体”字段选择目标本体。
3. 本体默认选中第一个可用项，并支持按页面能力多选。

本体列表来自当前项目绑定的本体资源。任务执行接口会携带本体的 ID、名称、描述和 code 等完整信息。

### 8.2 知识库入库

1. 选择“知识库”。
2. 在右侧“目标知识库”字段选择入库位置。

目标知识库同样只展示当前项目绑定的知识库。

## 九、配置执行主体和执行方式

### 9.1 执行主体

“执行主体”和“选择数字员工”均为必填：

1. 执行主体选择“数字员工”。
2. 从“选择数字员工”下拉框选择实际执行者。

下拉框只展示当前项目绑定的数字员工。

### 9.2 单次执行

选择“单次执行”后，选择精确到分钟的年月日时分：

| 字段 | 说明 |
| --- | --- |
| 执行时间 | 必填，默认打开模板时的当前时间 |

单次执行不需要填写采集时间范围。

### 9.3 按周期执行

选择“按周期执行”后，先选择周期类型：

| 周期类型 | 需要填写的内容 |
| --- | --- |
| 每天 | 执行时分 |
| 每周 | 可多选周一至周日，并选择执行时分 |
| 每双周 | 可多选周一至周日，并选择执行时分 |
| 每月 | 可多选 1 日至 31 日，并选择执行时分 |
| 每年 | 选择月、日、时、分 |

还可以填写“生效日期区间”。该字段可选，留空表示始终生效。

### 9.4 按间隔执行

选择“按间隔执行”后填写：

| 字段 | 是否必填 | 规则 |
| --- | --- | --- |
| 每几小时 | 是 | 必须为整数，最小 1 小时 |
| 执行日 | 是 | 可多选周一至周日 |
| 生效日期区间 | 否 | 留空表示始终生效 |

后端会根据结构化配置生成 `cron_expr`，由运营任务调度程序按计划触发。

## 十、确认执行并进入任务会话

完成模板配置后，点击“确定”：

1. 系统保存任务模板配置。
2. 系统创建或启动任务会话。
3. 页面自动进入聊天会话。
4. 系统按照模板字段生成首条任务消息并自动发送给所选数字员工。

发送到会话的资料采集配置使用以下最新字段：

- 采集方式
- 采集来源
- 入库方式
- 入库位置
- 执行方式
- 执行时间

不会再使用旧版的“采集渠道、采集账号或地址、采集主题”等字段。

示例消息结构：

```text
请处理以下资料采集与整理任务：

## 关联需求
- 需求名称：采集企业 AI Agent 落地案例
- 需求描述：采集近一个月企业 AI Agent 落地案例并保留来源

## 运营任务信息
- 运营项目：企业 AI 运营项目
- 任务名称：采集企业 AI Agent 落地案例 - 素材采集

## 资料采集配置
- 采集方式：互联网采集
- 采集来源：公开网页、行业媒体和微信公众号文章
- 入库方式：本体
- 入库位置：企业 AI Agent 案例
- 执行方式：单次执行
- 执行时间：2026-08-08 14:30
```

## 十一、跟踪任务状态

任务卡片右上角展示任务状态，不同状态使用不同颜色：

| 状态 | 页面行为 |
| --- | --- |
| 待开始 | 默认显示状态；鼠标经过时隐藏状态并显示“执行”按钮 |
| 进行中 | 不再显示执行按钮，可进入任务会话查看进展 |
| 已完成 | 不显示执行按钮，可打开任务会话查看成果 |
| 执行失败 | 查看任务会话中的异常信息，并核对资源和连接器配置 |

任务列表默认按“待开始 → 进行中 → 已完成”排序；状态相同时，创建时间最近的排在前面。

## 十二、查看采集成果

### 12.1 打开会话资源面板

在任务会话右上角点击资源按钮，可以查看：

- 当前会话：文件、本体。
- 当前员工：知识、技能、本体、模型。
- 当前项目：文件、知识、代码（研发项目）、本体。

运营项目常用的是“当前会话”的文件和本体，以及“当前项目”的共享知识库和共享本体。

### 12.2 文件预览

点击文件后会在右侧打开文件预览页，支持同时打开多个 Tab：

- 点击预览页左上角三横线，只收起或展开资源小面板。
- 收起资源小面板后，已打开的文件预览页面和 Tab 会继续保留。
- 点击 Tab 上的关闭按钮，才会关闭对应文件预览。
- 可使用预览区右上角按钮下载或复制文件内容。

### 12.3 本体成果

选择本体入库后，可在当前会话或当前项目的本体列表中查看对应对象。对象详情会读取完整详情数据，而不是只展示列表摘要。

## 十三、项目详情中的辅助管理

### 13.1 账号 Tab

用于维护运营账号。顶部操作顺序为：

1. 全部账号筛选
2. 新增账号
3. 新建会话
4. 刷新

### 13.2 资源 Tab

项目资源 Tab 展示项目绑定的共享资源：

- 共享文件
- 共享知识库
- 共享本体

共享知识库和共享本体与“新建/编辑项目空间”中的绑定项目资源保持一致。

### 13.3 成员 Tab

顶部操作顺序为：添加成员、新建会话、刷新。添加成员和绑定数字员工面板与项目小详情保持一致。

## 十四、常见问题

| 问题 | 处理建议 |
| --- | --- |
| 新建项目时资源下拉为空 | 确认当前账号拥有个人或企业知识、本体，以及可用个人助理或数字员工 |
| 新建项目提示“项目名称已存在” | 修改项目名称后重新提交 |
| 新增需求后切到了账号 Tab | 刷新前端版本；当前版本新增完成后应停留在需求 Tab |
| 需求无法拆分 | 检查需求编号、项目成员和负责人是否有效 |
| 任务没有执行按钮 | 只有待开始任务在鼠标经过卡片时显示执行按钮 |
| 任务没有“打开任务会话” | 未执行的任务不会生成可打开的任务会话 |
| 任务模板没有知识库或本体 | 确认项目已绑定对应资源，并重新打开任务模板 |
| 任务模板没有数字员工 | 确认项目已绑定数字员工资源 |
| 周期或间隔配置无法提交 | 检查必填的周期、执行日、执行时间或间隔小时数是否填写完整 |
| 进入聊天后没有自动消息 | 检查任务执行接口是否返回会话 ID，以及会话首条消息发送是否成功 |
| 对话仍显示旧采集字段 | 更新 `OPLOOP_TASK_START_PROMPT_COLLECT` 提示词并重启后端服务 |
| 文件预览关闭资源列表后消失 | 更新前端版本；当前版本只允许通过预览 Tab 关闭文件预览 |
| 采集任务没有产出 | 检查连接器、数字员工、来源资源权限和任务会话中的异常信息 |

| 功能 | 接口 |
| --- | --- |

## 十六、操作检查清单

启动采集任务前，建议逐项确认：

- [ ] 项目类型为运营项目。
- [ ] 项目已绑定知识库、数字员工和本体。
- [ ] 需求名称和描述能够明确表达采集目标。
- [ ] 拆分任务的名称、描述和负责人正确。
- [ ] 采集方式及对应来源已填写。
- [ ] 入库方式及入库位置已填写。
- [ ] 已选择正确的项目数字员工。
- [ ] 执行方式和时间配置完整。
- [ ] 连接器及目标资源对当前账号可用。
- [ ] 点击确定后已自动进入任务会话并发送首条消息。
