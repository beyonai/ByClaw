# 资源权限说明

本文说明资源中心五类资源在个人 tab、企业 tab 下的展示范围与操作权限口径。

## 资源类型

五类资源包括：

- 数字员工/个人助理：`DIG_EMPLOYEE`
- 知识：`KG_DOC`、`KG_DB`、`KG_QA`、`KG_TERM`
- 工具：`AGENT`、`MCP`、`TOOLKIT`、`TOOL`、`MCP_TOOL`
- 对象：`OBJECT`
- 视图：`VIEW`

## 列表范围

个人 tab：

- 个人助理查询 `owner_type=personal` 中我创建、我管理、我使用的资源，并额外展示当前默认个人助理和默认超级助手。
- 个人知识查询个人资源，并额外展示当前用户绑定的默认个人知识库。
- 个人工具、对象、视图查询个人资源中我创建或我被授权的资源。
- 命中当前用户使用黑名单的资源不展示。

企业 tab：

- 企业数字员工查询 `owner_type=enterprise` 的数字员工，不要求必须由当前用户创建或授权给当前用户。
- 企业知识、工具、对象、视图按企业资源全量查询。
- 命中当前用户使用黑名单的资源不展示。
- 组织筛选时按资源归属组织 `man_org_id` 收口。

## 补充说明

- 有管理权限指满足任一条件：平台管理员、资源创建人、资源归属组织管理员、对该资源有有效 `ALLOW_MANAGE` 授权。
- 组织授权按组织树向下继承：授权或排除某个组织时，同时作用于该组织的所有下级组织。
- 组织继承采用运行时按 `path_code` 计算的方式，`au_privilege_grant` 只保存直接配置的组织，不为每个子组织复制授权记录。
- 红黑名单冲突时黑名单优先，例如父组织在红名单、子组织在黑名单，则该子组织及其下级组织无权访问。
- 用户加入、离开或调整组织后，会异步重建该用户的资源权限缓存。
- 使用授权维护权限复用管理权限口径；当前用户绑定的默认个人资源也允许维护使用授权。
- 使用申请的通用条件包括：资源允许门户授权、当前用户不是创建人、当前用户未命中使用黑名单、当前用户未已有使用权限、当前用户未已有待审核申请。
- 个人 tab 下知识、工具、对象、视图不走使用申请/使用审核链路，只允许有管理权限的人主动授权别人使用。
- 个人助理、默认个人助理、默认超级助手不允许管理授权、使用申请和使用审核。
- 默认超级助手是登录自动初始化的个人底座资源，`resource_code` 固定为 `{userCode}_main`，不允许授权给别人使用。
- 当 `DATASET_SYSTEM=WHALE_AGENT` 时，知识和工具均由外部智能体体系通过后端接口发布，本系统不允许编辑基础信息或注销数据。


## 资源中心生命周期

资源中心的知识（KG_DOC / KG_QA / KG_TERM）、工具（TOOLKIT / MCP / AGENT）、技能和技能组使用与数字员工一致的状态：0 草稿、1 待上架、2 已上架、3 已下架、-1 已注销。历史状态 3 作为可重新上架的下架记录，不执行历史数据迁移。

- 企业资源由有管理权限的人从草稿或下架状态上架，从上架状态下架；只有创建者或 adminvip 可以在草稿或下架状态注销。个人资源不提供上下架入口，创建者或 adminvip 可直接注销。
- 默认个人资源、内置技能与外部托管知识/工具继续遵循原有只读限制。技能组另保留现有租户隔离、adminvip 管理权限和安装快照引用校验；上下架组不改变成员技能或已安装快照。
- 下架保留知识内容、技能包及关联记录，仅停止运行态发布和使用；注销记录保留在管理列表，不能再次上架或恢复。注销仍执行资源引用校验，知识内容清理仅发生在注销流程。
- 我可用的、官方推荐默认只查询状态 2；我的资源可以分别筛选上架、下架及注销状态。技能组的 adminvip 管理入口提供状态筛选。
- 资源卡片菜单统一显示“上架数据”“下架数据”“注销数据”，确认弹窗使用相同语义。已注销记录不提供操作菜单和详情点击。

统一接口均为 POST，JSON 入参为 `{"resourceId":"资源ID"}`：

- `/byaiService/tool/shelfResource`：0 / 3 → 2。
- `/byaiService/tool/unShelfResource`：2 → 3。
- `/byaiService/tool/deregisterResource`：符合注销条件 → -1。

接口服务层再次验证状态和权限，生命周期事务锁定资源以防止并发操作覆盖注销状态。旧工具删除/恢复入口对上述资源转入同一流程，不能通过强制恢复参数恢复已注销数据。单条与批量权限查询统一返回 `canOnShelf`、`canOffShelf`、`canDelete`，`canRestore` 仅作为旧客户端的上架兼容字段，注销时恒为 false。
