# 工作组话题和上传文件总数

`GET /group-chats/{sessionId}/topics` 与 `GET /group-chats/{sessionId}/files` 的无游标首屏响应新增 `data.total`，类型为非负整数。该值是全部可见条目的数量，与当前页长度及 `hasMore` 无关，空列表为 0。后续游标页不重复统计，`total` 为 null 或省略，客户端沿用首屏总数；刷新首屏或切换工作组时更新总数。

话题总数使用与列表完全相同的群范围及可见条件：话题至少存在一条未撤回消息。上传文件总数复用现有附件投影，仅统计未归档、未撤回真人或员工消息的 `related_resources.files` 有效附件；损坏 JSON 和无效附件不计入，任务结果元数据不计入，同一文件出现在不同消息中分别计数。群成员权限校验仍在所有查询之前执行。

上传文件首屏按 100 条候选消息分批扫描并计算精确总数，响应仍只携带请求的文件页，不将全量附件加载到响应内存。该统计增加首屏读取量，续页维持原有游标查询，不重复扫描全群。默认及最大页大小仍分别为 20 和 50。

HACU 页签将 0 至 999 显示为具体数量，超过 999 显示为 `999+`，无需把列表页大小提高到 999。未取得总数时不能将部分页长度视为精确总数。

变更包含服务、DTO、Mapper SQL 和对应测试用例，不涉及数据库结构迁移。尚未执行测试、构建或生产数据性能验证。
