# 新增模型的简化表单与确定性填充

系统模型与个人模型共用新增流程。选择“快速配置模型”或输入能唯一识别的型号后，填充名称、类型、提供商、协议、地址和已知能力参数；API Key 由用户填写。Header、超时重试、可选基本信息、参数和应用配置默认折叠，保存时有错误则展开相关区域。

## 自动填充边界

- 仅对尚未保存的新增记录启用；编辑旧记录和“保存并继续”后的记录不自动重新计算能力。
- 只更新空白或上次自动填入且未修改的值。用户主动修改、清空、设为 0 或 false 都视为手动设置。密钥和自定义 Header 不参与模板填充。
- 型号精确匹配，不根据前缀猜能力。相同型号在多个渠道出现时，由用户明确选择渠道模板。
- 切换到未知型号时撤销旧的自动能力值，保留连接信息和手动设置。未知非图片模型需要确认并填写上下文长度；不再假设 202752 上下文或 65536 输出预算。
- 前端容量校验允许正整数，取消统一的 200000/65536 最低限制。输出预算可留空，不把建议输出预算当作模型上限。新增表单的型号、类型、协议、地址都匹配官方模板时，校验已登记的容量上限；自定义代理及旧记录不受该上限约束。
- 新增流程的自动调试同步当前采样参数和输出预算；未填参数不发送。已保存记录的既有调试模板与协议路径保留。

## 模板来源与维护

模板集中在 `modelFormPresets.ts`。首批包含 MiniMax-M3、DeepSeek 的明确 API 型号，并复用已有图片提供商预设及 Seedream 版本选项。

文本模型参数核对日期：2026-10-14。

- [MiniMax OpenAI 接口文档](https://platform.minimax.io/docs/api-reference/text-openai-api)：M3 上下文、采样默认值及 Thinking 格式。
- [DeepSeek 模型元数据](https://api-docs.deepseek.com/api/list-models/)及[接入说明](https://api-docs.deepseek.com/)：型号、上下文、Thinking 能力及地址。
- 图片模型沿用已支持的提供商注册表。Seedream 的 2K、URL、水印为当前单图调试默认配置。

模板中的 `maxTokens: 8192` 是系统建议的单次输出预算，不是上游容量上限。模型别名能力可能随供应商调整；更新模板应重新核对来源，不能自动修改已有数据库记录。自定义代理可有不同限制，应保留用户显式配置。

本功能不调用“一键完善全部模型参数”接口，不使用 LLM 猜参数，不新增数据库字段，不修改 DSH 或现有保存 API。cURL 导入及远程型号发现不在本次范围内。
